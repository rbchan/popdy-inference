Spatio-temporal variation in survival, recruitment, movement and abundance with the Jolly-Seber model


WILD(FISH) 8390
Inference for Models of Fish and Wildlife Population Dynamics

Overview

Jolly-Seber model

  • Extend CJS model to allow for recruitment
  • We no longer “condition on first capture”
  • Typically, we use the robust design

Bigger picture

  • We’re interested in modeling population dynamics
  • This framework allows for inference on all of the key processes
  • Potential to model spatial, temporal, and individual-level variation vital rates
  • Density-dependence and biotic interactions could be modeled too

Individual-based spatial population dynamics

Initial State \[ z_{i,1} \sim \mbox{Bernoulli}(\psi) \\ {\bf s}_{i,1} \propto \lambda_1(\bs) \]

Survival and Recruitment \[ z_{i,t} \sim \begin{cases} \mbox{Bernoulli}(z_{i,t-1}\phi) & \quad \text{if previously recruited} \\ \mbox{Bernoulli}(\alpha_t) & \quad \text{if not yet recruited} \end{cases} \]

Movement (Assuming random walk) \[ \bsit \begin{cases} \sim \mbox{Norm}(\bsitp, \tau^2) & \quad \text{if previously recruited} <br> \propto \lambda_t(\bs) & \quad \text{if not yet recruited} \end{cases} \]

Abundance (\(M\) is the upper bound of data augmentation) \[ N_t = \sum_{i=1}^M z_{i,t} \]

Simulating spatial JS data with robust design

Parameters and data dimensions

T <- 10      # years/primary periods
K <- 3       # 3 secondary sampling occasion
lambda <- 25 # Expected value of abundance in year 1
M <- 500     # Easiest way to simulate data is using data augmentation

beta <- 0.3 # Per-capital recruitment rate

sigma <- 0.1 # Scale parameter of encounter rate function

Simulating spatial JS data with robust design

Generate \(z\)

set.seed(034)
z <- recruitable <- died <- recruited <- matrix(0, M, T)
z[,1] <- rbinom(M, 1, lambda/M) # alive at t=1
recruitable[,1] <- 1-z[,1]
N <- integer(T)
N[1] <- sum(z[,1])
for(t in 2:T) {
    ER <- N[t-1]*beta # expected number of recruits
    prevA <- sum(recruitable[,t-1]) # Number available to be recruited
    alpha <- ER/prevA
    if(alpha > 1) stop("M isn't big enough")
    z[,t] <- rbinom(M, 1, (1-recruitable[,t-1])*z[,t-1]*phi +
                          recruitable[,t-1]*alpha)
    recruitable[,t] <- recruitable[,t-1]*(1-z[,t])
    N[t] <- sum(z[,t])  }

Bayesian inference

Spatial JS model in JAGS

JS-spatial.jag 
model {
phi ~ dunif(0,1)      ## Survival
beta ~ dunif(0, 5)    ## Per-capita recruitment rate
p0 ~ dunif(0,1)       ## Baseline capture probability
sigma ~ dunif(0, 2)   ## Scale parameter of capture function
psi ~ dunif(0,1)    
for(t in 1:T) {
  N[t] <- sum(z[,t])     ## Abundance
  ER[t] <- N[t]*beta     ## Expected number of recruits in year t
  totalAvail[t] <- sum(recruitable[,t])  ## nAvailable to be recruited
  alpha[t] <- ER[t]/totalAvail[t] } ## Pr(recruited in year t|available)
for(i in 1:M) {
  z[i,1] ~ dbern(psi)              ## Alive/dead state in year 1
  recruitable[i,1] <- 1 - z[i,1]   ## Recruitable next year if not recruited yet
  s[i,1] ~ dunif(xlim[1], xlim[2]) ## static activity centers
  s[i,2] ~ dunif(ylim[1], ylim[2])
  for(j in 1:J) {
    d[i,j] <- sqrt((s[i,1] - x[j,1])^2 + (s[i,2] - x[j,2])^2) ## Distance
    p[i,j] <- p0*exp(-d[i,j]^2/(2*sigma^2))                   ## Cap prob
    y[i,j,1] ~ dbin(z[i,1]*p[i,j], K)  }                      ## Data in year 1
  for(t in 2:T) {
    z[i,t] ~ dbern(z[i,t-1]*phi + recruitable[i,t-1]*alpha[t-1]) ## Alive/dead state 
    died[i,t] <- (z[i,t-1]==1) && (z[i,t]==0)                 ## Did this guy die?
    recruited[i,t] <- (z[i,t-1]==0) && (z[i,t]==1)            ## Or was it recruited?
    recruitable[i,t] <- recruitable[i,t-1]*(1-z[i,t])
    for(j in 1:J) {
      y[i,j,t] ~ dbin(z[i,t]*p[i,j], K) }  }                  ## Data in year t
  everAlive[i] <- sum(z[i,]) > 0  }
for(t in 2:T) {
  Deaths[t-1] <- sum(died[,t])             ## Total deaths each year
  Recruits[t-1] <- sum(recruited[,t]) }    ## Total recruits each year
Ntot <- sum(everAlive)                     ## Super-population size
}

Summary

This is perhaps the most general approach to modeling population dynamics, especially when the model includes a movement process.

Requires a lot of data on marked individuals, but it should be no surprise that we need a lot of data to understand complex processes.

Integrated population models can be used to draw inferences using this model and a combination of data on marked and unmarked individuals.
