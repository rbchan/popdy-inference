Open Populations and the Spatial Cormack-Jolly-Seber Model


WILD(FISH) 8390
Inference for Models of Fish and Wildlife Population Dynamics

Open populations


Overview

  • Population closure is an assumption we make to estimate density in short time periods.
  • If we want to study the processes governing spatial and temporal variation in density, we need to move beyond closed population models.
  • Open population SCR models allow us to model spatial and temporal variation in survival, recruitment, and movement.

Types of closure

Geographic closure

  • Animals cannot enter or leave the study area
  • But what is the study area in non-spatial settings?
  • What is a non-spatial setting?

Demographic closure

  • No births or deaths
  • Reasonable over short time periods
  • But temporal dynamics are often of chief interest

Two varieties of open mark-recapture models

Cormack-Jolly-Seber Model

  • Primarily used to estimate survival
  • When permanent emigration is possible, estimate is of “apparent survival” (\(\phi\))
  • Apparent survival is the probability of surviving and not leaving the study area permanently
  • CJS models are not used to estimate abundance or recruitment

Jolly-Seber model

  • Traditionally used to estimate abundance, (apparent) survival, and recruitment
Both classes of models can be made spatially explicit to study movement, among other things

Non-spatial CJS

Non-spatial CJS model

Notes

  • Typical scenario involves “releasing” indviduals and recapturing them over time
  • We don’t model initial capture process
  • Instead, we “condition on initial capture”
  • As an example, imagine releasing a bunch of tagged animals in a translocation study
  • Because we aren’t estimating \(N\), no data augmentation required
  • It is possible to estimate parameters using 1 sampling occasion per season
  • Robust design provides more information about \(p\)

Non-spatial CJS model

State model \[ z_{i,t} \sim \mbox{Bernoulli}(z_{i,t-1} \times \phi) \]

Observation model \[ y_{i,t} \sim \mbox{Bernoulli}(z_{i,t} \times p) \]

where

  • \(z_{i,t}\) is “alive state” of individual \(i\) at time \(t\)
  • \(\phi\) is “apparent survival”. Probability of being alive and not permanently emigrating.
  • \(y_{i,t}=1\) if individual was encountered, \(y_{i,t}=0\) otherwise.

Simulating CJS data without robust design

Parameters and dimensions

T <- 10               ## primary periods (eg, years)
K <- 1                ## only 1 secondary sampling occasion
n <- 25
phi <- 0.7
p <- 0.4
z <- matrix(NA, n, T)
y <- matrix(NA, n, T)
first <- rpois(n, 1)+1 ## random release dates

Generate \(z\) and \(y\)

for(i in 1:n) {
    z[i,first[i]] <- 1  ## Known alive at release
    y[i,first[i]] <- 1
    for(t in (first[i]+1):T) {
        z[i,t] <- rbinom(1, 1, z[i,t-1]*phi) ## Alive/dead state
        y[i,t] <- rbinom(1, 1, z[i,t]*p)     ## Data
    }
}

Non-spatial CJS model in JAGS

CJS-nonspatial.jag

model {

phi ~ dunif(0,1)
p ~ dunif(0,1)

for(i in 1:n) {
  z[i,first[i]] <- 1             ## Known alive at time of release
  for(t in (first[i]+1):T) {
    z[i,t] ~ dbern(z[i,t-1]*phi) ## Survives with probability phi
    y[i,t] ~ dbern(z[i,t]*p)     ## Detected with probability p
    }
  }

}

Spatial CJS

Spatial CJS

Why spatial?

  • Comes with all the benefits of other SCR models
  • Allows for movement between primary periods, making it possible to separate survival from permanent emigration
  • Movement itself may be of interest, such as in studies of dispersal

We begin by ignoring movement, but we use the robust design

Simulating spatial CJS data with robust design

Parameters and data dimensions

T <- 10       # primary occasions
K <- 3        # secondary occasions
n <- 25       # nIndividuals
phi <- 0.7
p0 <- 0.4     # baseline capture prob
sigma <- 0.1  # scale parameter

Traps, activity centers, and
detection probability

co <- seq(0.25, 0.75, length=5)
x <- cbind(rep(co, each=5),
           rep(co, times=5))
J <- nrow(x)
xlim <- ylim <- c(0,1)
s <- cbind(runif(n, xlim[1], xlim[2]),
           runif(n, ylim[1], ylim[2]))
d <- p.sp <- matrix(NA, n, J)
for(i in 1:n) {
    d[i,] <- sqrt((s[i,1]-x[,1])^2 +
                  (s[i,2]-x[,2])^2)
    p.sp[i,] <- p0*exp(-d[i,]^2/(2*sigma^2))
}

Generate \(z\) and \(y\)

z <- matrix(NA, n, T)
y.sp <- array(NA, c(n, J, K, T)) ## 4D array
first <- rpois(n, 1)+1 ## random release dates
for(i in 1:n) {
    z[i,first[i]] <- 1
    for(t in (first[i]+1):T) {
        z[i,t] <- rbinom(1, 1,
                         z[i,t-1]*phi)
        for(j in 1:J) {
            y.sp[i,j,1:K,t] <- rbinom(K, 1,
                z[i,t]*p.sp[i,j])
        }
    }
}

Spatial CJS model in JAGS

CJS-spatial.jag

model {

phi ~ dunif(0,1)     ## Apparent survival
p0 ~ dunif(0,1)      ## Baseline capture prob
sigma ~ dunif(0, 2)  ## Scale parameter of detection function

for(i in 1:n) {      ## Loop over individuals
  s[i,1] ~ dunif(xlim[1], xlim[2]) # static activity centers
  s[i,2] ~ dunif(ylim[1], ylim[2])
  for(j in 1:J) {    ## Loop over traps
    d[i,j] <- sqrt((s[i,1] - x[j,1])^2 + (s[i,2] - x[j,2])^2)
    p[i,j] <- p0*exp(-d[i,j]^2/(2*sigma^2)) ## Capture prob
    }
  z[i,first[i]] <- 1 ## Condition on first encounter
  for(t in (first[i]+1):T) {
    z[i,t] ~ dbern(z[i,t-1]*phi) ## Model subsequent encounters
    for(j in 1:J) {
      for(k in 1:K) {
        y[i,j,k,t] ~ dbern(z[i,t]*p[i,j])
        }
      }
    }
  }

}

Spatial CJS with movement

Modeling dispersal among years

What if activity centers move between years?

  • Could affect estimates of detection parameters
  • More importantly, might provide opportunity to study dispersal

Potential movement models}

  • Random walk: \({\bm s}_t \sim \mbox{Normal}({\bm s}_{t-1}, \tau^2)\)
  • Random walk with attraction point: \({\bm s}_t \sim \mbox{Normal}({\bm s}_{t-1} + \rho(\bar{\bm s} - {\bm s}_{t-1}), \tau^2)\)
  • Extensions can be made to allow for resource selection, landscape resistance, etc.1.

  1. https://esajournals.onlinelibrary.wiley.com/doi/full/10.1002/ecy.3473

Simulating spatial CJS data with dispersal

Parameters and data dimensions

T <- 10; K <- 5; n <- 25 ## same as before
phi <- 0.9; p0 <- 0.4; sigma <- 0.05
## dispersal parameter (of random walk)
tau <- 0.05

Activity centers take a random walk

## state-space should be bigger
xlim <- ylim <- c(0, 1)
first <- rpois(n, 1)+1
s <- array(NA, c(n, 2, T))
for(i in 1:n) {
    s[i,,first[i]] <-
        cbind(runif(1, xlim[1], xlim[2]),
              runif(1, ylim[1], ylim[2]))
    for(t in (first[i]+1):T) {
        s[i,1,t] <- rnorm(1, s[i,1,t-1], tau)
        s[i,2,t] <- rnorm(1, s[i,2,t-1], tau)
    }
}
d <- p <- array(NA, c(n, J, T))
for(i in 1:n) {
    for(t in 1:T) {
        d[i,,t] <- sqrt((s[i,1,t]-x[,1])^2 +
                        (s[i,2,t]-x[,2])^2)
        p[i,,t] <- p0*exp(-d[i,,t]^2 /
                          (2*sigma^2))
    }
}

Generate \(z\) and \(y\)

z <- matrix(NA, n, T)
y.move <- array(NA, c(n, J, T)) 
for(i in 1:n) {
    z[i,first[i]] <- 1
    for(t in (first[i]+1):T) {
        z[i,t] <- rbinom(1, 1, z[i,t-1]*phi)

Spatial CJS model with dispersal in JAGS

CJS-spatial-move.jag

model {

phi ~ dunif(0,1)
p0 ~ dunif(0,1)
sigma ~ dunif(0, 2)
tau ~ dunif(0, 2)
tauprec <- 1/tau^2 # must convert tau to precision

for(i in 1:n) {
  s[i,1,first[i]] ~ dunif(xlim[1], xlim[2])
  s[i,2,first[i]] ~ dunif(ylim[1], ylim[2])
  for(j in 1:J) {
    d[i,j,first[i]] <- sqrt((s[i,1,first[i]] - x[j,1])^2 + (s[i,2,first[i]] - x[j,2])^2)
    p[i,j,first[i]] <- p0*exp(-d[i,j,first[i]]^2/(2*sigma^2))
    }
  z[i,first[i]] <- 1
  for(t in (first[i]+1):T) {
    s[i,1,t] ~ dnorm(s[i,1,t-1], tauprec)#T(xlim[1], xlim[2])
    s[i,2,t] ~ dnorm(s[i,2,t-1], tauprec)#T(ylim[1], ylim[2])
    for(j in 1:J) {
      d[i,j,t] <- sqrt((s[i,1,t] - x[j,1])^2 + (s[i,2,t] - x[j,2])^2)
      p[i,j,t] <- p0*exp(-d[i,j,t]^2/(2*sigma^2))
      }
    z[i,t] ~ dbern(z[i,t-1]*phi)
    for(j in 1:J) {
      y[i,j,t] ~ dbin(z[i,t]*p[i,j,t], K)
#      for(k in 1:K) { y[i,j,k,t] ~ dbern(z[i,t]*p[i,j,t]) }
  } } } 

}
