Occupancy models:
covariates and prediction


WILD(FISH) 8390
Inference for Models of Fish and Wildlife Population Dynamics

Overview

Explaining variation in occupancy and detection probability with covariates is central to reliable prediction and scientific investigation.


In static occupancy models, there are two types of covariates:

  • Site covariates vary among sites but not among occasions.
  • Observation covariates may vary among sites and occasions


In both cases, covariates can be continuous or categorical.

Observation covariates cannot be used to describe variation in occupancy because occupancy is assumed to be constant over time.

Covariates

State model \[ \small \begin{gather*} \mathrm{logit}(\psi_i) = \beta_0 + \beta_1 {\color{blue} x_{i1}} + \beta_2 {\color{blue} x_{i2}} + \cdots \\ z_i \sim \mathrm{Bern}(\psi_i) \end{gather*} \]

Observation model \[ \small \begin{gather*} \mathrm{logit}(p_{ij}) = \alpha_0 + \alpha_1 {\color{blue} x_{i1}} + \alpha_2 {\color{Coral} w_{ij}} + \cdots \\ y_{ij} \sim \mathrm{Bern}(z_i\times p_{ij}) \end{gather*} \]

\(\color{blue} x_1\) and \(\color{blue} x_2\) are site covariates.
Examples: elevation, forest cover, distance to water.

\(\color{Coral} w\) is an observation covariate.
Examples: time of day, observer, wind.

Simulation

Two continuous covariates and one categorical covariate with 2 levels.

nSites <- 200; nVisits <- 4; set.seed(83) # Make it reproducible
elev <- rnorm(nSites,5000,500) # Site covariate (continuous)
forest <- rnorm(nSites,100,10) # Another continuous site covariate
temp <- matrix(sample(c("Cold", "Hot"), size=nSites*nVisits,
                      replace=TRUE),
               nrow=nSites, ncol=nVisits) # Categorical obs covar
tempHot <- ifelse(temp=="Hot", 1, 0)      # Dummy variable

Coefficients, \(\psi\), and \(p\)

beta0 <- 5; beta1 <- -0.001; beta2 <- 0
psi <- plogis(beta0 + beta1*elev + beta2*forest)
alpha0 <- -6.5; alpha1 <- 0.001; alpha2 <- 2
p <- plogis(alpha0 + alpha1*elev + alpha2*tempHot)

Simulate occupancy and detection data

z <- rbinom(nSites, size=1, psi)            ## pres/absence
y <- matrix(NA, nrow=nSites, ncol=nVisits)
for(i in 1:nSites) {
    y[i,] <- rbinom(nVisits, size=1, prob=z[i]*p[i,])
}

Standardizing

It’s almost always a good idea to standardize continuous covariates.

Standardizing involves subtracting the mean and then dividing by the standard deviation.

mean.elev <- mean(elev); mean.forest <- mean(forest)
sd.elev <- sd(elev); sd.forest <- sd(forest)
elev_s <- (elev-mean.elev)/sd.elev
forest_s <- (forest-mean.forest)/sd.forest
siteCovs(umf)$elev_s <- elev_s
siteCovs(umf)$forest_s <- forest_s

Standardizing makes it easier to find the maximum likelihood estimates (MLEs) and it facilitates comparison of estimates.

We just have to remember to back-transform covariates when graphing predictions.

The BUGS model

occupancy-model-covs.jag 
model {

# Priors for occupancy coefficients
beta0 ~ dnorm(0, 0.5)  # 0.5 is 1/variance
beta1 ~ dnorm(0, 0.5)
beta2 ~ dnorm(0, 0.5)

# Priors for detection coefficients
alpha0 ~ dnorm(0, 0.5)  
alpha1 ~ dnorm(0, 0.5)
alpha2 ~ dnorm(0, 0.5)

for(i in 1:nSites) {
  logit(psi[i]) <- beta0 + beta1*elev[i] + beta2*forest[i]
  z[i] ~ dbern(psi[i])            # Latent presence/absence
  for(j in 1:nOccasions) {
    logit(p[i,j]) <- alpha0 + alpha1*elev[i] + alpha2*tempHot[i,j]
    y[i,j] ~ dbern(z[i]*p[i,j])   # Data
  }
}

sitesOccupied <- sum(z)

}

Bayesian prediction

Every MCMC iteration represents a sample from the posterior distribution.


Each sample of the occupancy and detection coefficients can be used to make a prediction.


The collection of predictions can be used to summarize the posterior predictive distribution.


We will look at the distribution of prediction lines.

Summary of static occupancy models

Assumptions are made explicit by the model description, but it’s worth emphasizing that:

  • Occupancy is assumed to remain constant at each site during the sampling period
  • The definition of a ‘site’ is critical, but can difficult in some situations, such as in camera studies.
  • Abundance is assumed to be unimportant
  • Observations are assumed to be independent, conditional on latent variables and covariates

These assumptions can be relaxed if we have enough data.

  • Dynamic occupancy models

  • Occupancy evolves as a function of local colonization and extinction

  • \(N\)-mixture models

  • Focus is on local abundance, rather than presence/absence

We’ll talk more about design issues later
