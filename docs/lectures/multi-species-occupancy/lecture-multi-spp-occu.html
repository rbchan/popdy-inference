Community occupancy models

Community occupancy model

Species may go undetected for a couple reason:

  1. They are rare and are not present in our sample.
  2. They are present in our sample but are cryptic.


Older methods like rarefaction attempt to address the first issue but not the second.

We have to address both issues to obtain unbiased estimates of community parameters like species richness.

Community occupancy model

Occupancy of species \(i\) present at site \(j\):

\[ z_{ij} \sim \mathrm{Bern}(\psi_i) \]

Detection data for species \(i\) at site \(j\) on occasion \(k\):

\[ y_{ijk} \sim \mathrm{Bern}(z_{ij} \times p_i) \]


Species-specific parameters can be modeled as functions of covariates and/or regarded as random effects. Here’s an example without covariates:

\[ \mathrm{logit}(\psi_j) \sim \mathrm{Norm}(\mu_{\psi}, \sigma^2_{\psi}) \]

\[ \mathrm{logit}(p_j) \sim \mathrm{Norm}(\mu_{p}, \sigma^2_{p}) \]

Species richness

What do we do if we don’t know how many species are in the community?

Two options:

  1. Model only the species that were in the sample.
    • This won’t let you estimate actual richness, but it will let you account for species (in the sample) that were present but not detected at some sites.
  1. Estimate the number of species that were not detected in the sample.
    • This can be accomplished using data augmentation.
    • Ideally, we would use some sort of “species checklist” to focus on species that could have been present.

Simulation without covariates

N <- 50    # n_species
J <- 40    # n_sites
K <- 3     # n_visits

## Occupancy as logit-normal random effects 
set.seed(34020)
mu_logit_psi <- -2
sd_logit_psi <- 1
psi <- plogis(rnorm(n=N, mean=mu_logit_psi, sd=sd_logit_psi))

## Detection prob as logit-normal random effects
mu_logit_p <- -1
sd_logit_p <- 0.5
p <- plogis(rnorm(n=N, mean=mu_logit_p, sd=sd_logit_p))

## Occupancy and data
z <- matrix(NA, nrow=N, ncol=J) # latent occupancy state for species i at site j
yall <- array(NA, dim=c(N,J,K)) # Data (except we don't know spp that weren't detected)
for(i in 1:N) {
  z[i,] <- rbinom(n=J, size=1, prob=psi[i])
  for(j in 1:J) {
    yall[i,j,] <- rbinom(n=K, size=1, prob=z[i,j]*p[i])
  }
}

JAGS model ignoring missed species

model {

mu_logit_psi ~ dnorm(0, 1)
sd_logit_psi ~ dexp(1)

mu_logit_p ~ dnorm(0, 1)
sd_logit_p ~ dexp(1)

for(i in 1:n_species) {
  logit_psi[i] ~ dnorm(mu_logit_psi, 1/sd_logit_psi^2)
  logit_p[i] ~ dnorm(mu_logit_p, 1/sd_logit_p^2)
  psi[i] <- ilogit(logit_psi[i])
  p[i] <- ilogit(logit_p[i])
  for(j in 1:n_sites) {
    z[i,j] ~ dbern(psi[i])
    for(k in 1:n_occasions) {
      y[i,j,k] ~ dbern(z[i,j]*p[i])
    }
  }
}


}

JAGS model ignoring missed species

We shouldn’t be surprised by upward bias in estimation of occupancy and detection parameters because we’re ignoring species with low detection/occupancy probabilities.

Expanding the model to estimate richness


We can use data augmentation to infer how many species were missed, and thus estimate the size of the entire community.


Here’s the expanded part of the model:

\[ w_i \sim \mathrm{Bern}(\Omega) \\ z_{ij} \sim \mathrm{Bern}(w_i \times \psi_{i}) \]

where \(w_i\) indicates if species \(i\) is part of the community such that \(N=\sum_{i=1}^M w_i\), and the expected number of species in the community is \(E(N)=M \Omega\).

JAGS model estimating richness

model {

mu_logit_psi ~ dnorm(0, 1)
sd_logit_psi ~ dexp(1)

mu_logit_p ~ dnorm(0, 1)
sd_logit_p ~ dexp(1)

omega ~ dunif(0,1)

for(i in 1:M) {
  w[i] ~ dbern(omega)
  logit_psi[i] ~ dnorm(mu_logit_psi, 1/sd_logit_psi^2)
  logit_p[i] ~ dnorm(mu_logit_p, 1/sd_logit_p^2)
  psi[i] <- ilogit(logit_psi[i])
  p[i] <- ilogit(logit_p[i])
  for(j in 1:n_sites) {
    # z[i,j] ~ dbern(w[i]*psi[i])
    z[i,j] ~ dbern(psi[i])
    for(k in 1:n_occasions) {
      # y[i,j,k] ~ dbern(z[i,j]*p[i])
      y[i,j,k] ~ dbern(w[i]*z[i,j]*p[i])
    }
  }
}

N <- sum(w) # Species richness


}

Additional community parameters

We can use the \(z\) matrix to estimate community parameters other than richness, including the Jaccard similarity index, comparing any two sites (\(j\) and \(j'\)):

\[ S_{j,j'} = \frac{\sum_i z_{ij} z_{ij'}}{\sum_i z_{ij} + \sum_i z_{ij'} - \sum_i z_{ij} z_{ij'}} \]
