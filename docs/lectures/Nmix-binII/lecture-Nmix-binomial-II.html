Model selection

Model selection

In scientific contexts, we want models that describe natural processes and allow us to evaluate hypotheses.


Models should be predictive, but they shouldn’t be crafted with the sole goal of prediction in mind.


Scientists typically don’t care about prediction if the model doesn’t help us learn about the processes that gave rise to the data.


Nonetheless, predictive performance is often the best way to compare models and avoid underfitting and overfitting.


Make sure the models being compared were motivated by clear hypotheses.

Model selection

Prediction accuracy increases with model complexity up to a point, until overfitting kicks in.

The best way to determine if a model is too simplistic or too complex is to compare predictions to new observations.

However, we rarely have the resources to collect additional data for the sake of evaluating predictive performance.

A cheaper (albeit less desirable) alternative is to use cross-validation:

  • Split data into K partitions
  • Fit model to the data in K-1 partitions
  • Predict the holdout partition
Information criteria like AIC and WAIC yield similar predictive rankings as cross-validation, but with less computation.

Model selection with AIC

Most information criteria (IC) take on a form like this: \[ \mathrm{IC} = \mathrm{fit} + \mathrm{penalty} \]

where fit describes the in-sample predictive accuracy and penalty describes model complexity.

In the case of Akaike’s “An Information Criterion”, which approximates leave-one-out cross validation, fit is described by the likelihood and the penalty is determined by the number of parameters: \[ \mathrm{AIC} = -2 \log(L) + 2P \] where \(L\) is the likelihood evaluated at the MLE and \(P\) is the number of parameters.

The lower the AIC, the better the out-of-sample predictive performance.

WAIC

Watanabe’s widely applicable information criterion (WAIC) is a generalization of AIC suitable for Bayesian models.

As before, we have

\[ \mathrm{WAIC} = \mathrm{fit} + \mathrm{penalty} \]

The measure of fit in this case is the log-pointwise-predictive-density:

\[ \mathrm{lppd} = \sum_{i=1}^M \log\left(\frac{1}{S} \sum_s p(y_i|\theta_s)\right) \]

The penalty is proportional to the posterior variance: \[ \mathrm{penalty} = \sum_{i=1}^M \mathrm{Var}(\log p(y_i|\theta_s))) \]

The BUGS model

Notice modswitch, which we can use to include/exclude predictors.

Nmix-model-grouse.jag

model {

#beta0 ~ dnorm(0, 0.5)  
lambda.intercept ~ dunif(0, 5)
beta0 <- log(lambda.intercept)
beta1 ~ dnorm(0, 0.5)
beta2 ~ dnorm(0, 0.5)
beta3 ~ dnorm(0, 0.5)

alpha0 ~ dnorm(0, 0.5)  
alpha1 ~ dnorm(0, 0.5)

for(i in 1:nSites) {
  elevation[i] ~ dnorm(0, 1) # Missing values drawn from prior
  utmN[i] ~ dnorm(0, 1)      # Ditto
  utmE[i] ~ dnorm(0, 1)      # Ditto
  log(lambda[i]) <- beta0 + beta1*elevation[i]*modswitch[1] +
    beta2*utmE[i]*modswitch[2] + beta3*utmN[i]*modswitch[3] 
  N[i] ~ dpois(lambda[i])    # Latent local abundance
  for(j in 1:nOccasions) {
    temp[i,j] ~ dnorm(0,1)
    logit(p[i,j]) <- alpha0 + alpha1*temp[i,j]*modswitch[4]
    y[i,j] ~ dbin(p[i,j], N[i])   # Data
    ld.y[i,j] <- logdensity.bin(y[i,j], p[i,j], N[i])
  }
  ld.y.dot[i] <- sum(ld.y[i,])
}

totalAbundance <- sum(N[1:nSites])

}

WAIC

\[ \mathrm{WAIC} = -2\left(\mathrm{lppd} - \sum_i \mathrm{Var}(\log p(y_i|\theta))\right) \]

waic <- function(x) {
    ## Parameter names
    vars <- coda::varnames(x)
    ## Extract log-density of y at each site for each post sample
    ld.samples <- as.matrix(x[,grep("ld.y.dot", vars)])
    ## Compute log-pointwise-predictive-density
    lppd <- sum(log(colMeans(exp(ld.samples))))
    ## Compute penalty
    penalty <- sum(apply(ld.samples, 2, var))
    ## Return WAIC
    return(-2*(lppd-penalty))
}

Goodness-of-fit

Goodness-of-fit

Distributional assumptions determine the expected values and the expected variance of the random variables, including the data.

Overdispersion occurs when there is more variance in the data than expected by the model. Goodness-of-fit methods assess overdispersion and underdispersion.

If the model does not fit the data very well because of overdispersion, there are several remedial actions:

  • Scientific approach
    • Figure out why there is unexplained variation
    • Perhaps there were unmeasured covariates or you need a better process model
  • Statistical approach
    • Soak up variation with random effects
    • Use a different distribution (we’ll start here)

Changing the distribution for \(N\)

Standard Poisson-binomial \(N\)-mixture model (without covariates): \[ N_i \sim \mathrm{Poisson}(\lambda) \\ y_{ij} \sim \mathrm{Binomial}(N_i, p) \]

We can replace the Poisson distribution with other distributions that allow for greater variance in \(N\). Two common examples are the negative binomial: \[ N_i \sim \mathrm{NegBin}(\lambda_i, \kappa) \] where \(\lambda_i\) is the expected value of \(N\) and \(\kappa\) is the dispersion parameter.

Another option is the zero-inflated Poisson:

\[ N_i \sim \mathrm{Poisson}(\lambda_i z_i) \\ z_i \sim \mathrm{Bern}(\psi) \]

\[ N_i \sim \mathrm{ZIPoisson}(\lambda_i,\psi) \]

where \(\psi\) is the expected proportion of sites with excess zeros.

Simulating data from ZIP model

Zero-inflated Poisson model

\[ N_i \sim \mathrm{Poisson}(\lambda_i z_i) \\ z_i \sim \mathrm{Bern}(\psi) \]

\[ N_i \sim \mathrm{ZIPoisson}(\lambda_i,\psi) \]

R code

nSites <- 20
nVisits <- 3
psi <- 0.5   # Proportion of extra-Poisson zeros
z <- rbinom(n=nSites, size=1, prob=psi) # Extra zeros
lam <- 5     # expected count when z=1
N <- rpois(n=nSites, lambda=lam*z)      # abundance at each site
p <- 0.5     # detection prob
y <- matrix(NA, nSites, nVisits)
for(i in 1:nSites) {
    y[i,] <- rbinom(n=nVisits, size=N[i], prob=p) # count data
}

Goodness-of-fit in unmarked

The parametric bootstrap can be used to assess model fit:

  • Simulate a dataset from the fitted model
  • Fit the model to the new dataset
  • Compute a fit statistic
  • Repeat steps 1-3 several hundred/thousand times
  • Compare the distribution of the expected fit statistic to the fit statistic associated with the actual data.

The fit statistic associated with the actual data should not be in an extreme quantile of the distribution of the expected values.

Assuming a type I error rate of 0.05, the \(p\)-value should be >0.05 if the model fits the data well, which is the null hypothesis.

fitstat <- function(fm) { ## Sum of squared-residuals

Bayesian fit assessments


In a Bayesian analysis, we can assess model fit using a posterior predictive check (PPC).


The PPC compares the posterior distribution of a fit statistic, to the posterior distribution of a fit statistic computed from simulated data.


The two distributions should look similar if the model fits well.

BUGS model with fit stats

Nmix-model-grouse2.jag

model {

lambda.intercept ~ dunif(0, 5)
beta0 <- log(lambda.intercept)
beta1 ~ dnorm(0, 0.5)
beta3 ~ dnorm(0, 0.5)

alpha0 ~ dnorm(0, 0.5)  
alpha1 ~ dnorm(0, 0.5)

for(i in 1:nSites) {
  elevation[i] ~ dnorm(0, 1)
  utmN[i] ~ dnorm(0, 1)
  utmE[i] ~ dnorm(0, 1)
  log(lambda[i]) <- beta0 + beta1*elevation[i] + beta3*utmN[i]
  N[i] ~ dpois(lambda[i])         # Latent local abundance
  N.new[i] ~ dpois(lambda[i])     # Predicted local abundance
  for(j in 1:nOccasions) {
    temp[i,j] ~ dnorm(0,1)
    logit(p[i,j]) <- alpha0 + alpha1*temp[i,j]
    y[i,j] ~ dbin(p[i,j], N[i])              # Data
    resid[i,j] <- y[i,j]-N[i]*p[i,j]         # Residual
    y.new[i,j] ~ dbin(p[i,j], N.new[i])          # Predicted data
    resid.new[i,j] <- y.new[i,j]-N.new[i]*p[i,j] # Predicted residual
  }
}
SSE <- sum(resid^2)             # Fit stat
SSE.new <- sum(resid.new^2)     # Predicted fit stat

totalAbundance <- sum(N[1:nSites])

}
